## GitHub Pages
1. Create a repository, for example `zyka-gold`.
2. Upload all files from this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Replace `YOUR-GITHUB-USERNAME` in `sitemap.xml` and `robots.txt` with your GitHub username.
7. If using a custom domain later, update those two files with the final domain.
